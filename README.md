# Куран-и Керим · القرآن الكريم

Свещеният Коран на арабски с превод на български, 25 известни рецитатора и официалните времена за намаз за всеки град и село в България.

**Отвори:** https://me7ko-dev.github.io/quran-kerim/

Работи на телефон, таблет и компютър. Може да се инсталира като приложение („Добави към началния екран“) и чете текста без интернет.

## Какво може

- **Четене** — мусхаф по рикаят на Хафс, шрифт KFGQPC Uthmanic Hafs; изглед „айет по айет“ с превод или „мусхаф“ (непрекъснат текст); уголемяване на арабския текст и превода; светла, сепия и тъмна тема.
- **Слушане** — само избран айет, поредно (с Бисмиллях в началото на сурата и продължаване със следващата сура) или повторение ×2…×10 за заучаване; скорост 0.75–1.5×; текущият айет се осветява и страницата го следва; управление от заключения екран.
- **Заучаване** — откъс от айети (напр. 2:1–5): всеки айет се чете 1–10 пъти, после целият откъс отначало 1–10 пъти или без край; откъсът се осветява в текста.
- **Рецитатори** — ал-Афаси, Абдулбасит (муреттел и муджеввед), ал-Хусари (и муаллим), ал-Миншави, ас-Судейс, аш-Шурейм, ал-Муайкли, ад-Досари, ал-Гамиди и др. (25 общо).
- **Намаз** — следващото време с обратно броене, всеки ден, месечен календар; търсене на 6 900+ населени места (и на латиница) или „Намери ме“.
- **Кибла** — компас на телефона с посоката към Кябе (с поправка за магнитното отклонение в България), градуси, разстояние до Мека и часът, в който слънцето е точно в посоката на киблата.
- **Отметки, търсене** в превода, преход към айет (напр. `2:255`), продължаване от последното място.

## Откъде са времената за намаз

От официалния календар на [Главно мюфтийство](https://www.grandmufti.bg/bg/home/vremena-za-namaz.html).
Проверено е, че календарът за всичките 48 града е **таблицата за София + постоянна разлика в минути**
(напр. Варна −18, Кърджали −8, Мадан −6), която следва географската дължина (4 мин на градус).

- За 48-те града приложението показва официалните времена минута по минута.
- За всяко друго място взима най-близкия официален град и добавя разликата по дължина — по същото правило.
  В Настройки може да се избере вместо това да се показват точно времената на града.
- GitHub Actions (`.github/workflows/update-prayer.yml`) проверява сайта на Мюфтийството на 2-ро число всеки месец с `tools/update-prayer.mjs` и записва `data/prayer.json`. Може да се пусне и ръчно: Actions → „Времена за намаз“ → Run workflow.

## Разработка

Статичен сайт без build: HTML, CSS и JavaScript модули.

```
node tools/serve.mjs 8931            # локален сървър
node tools/update-prayer.mjs         # обнови времената от grandmufti.bg
node tools/check-reciters.mjs        # провери, че аудиото на рецитаторите е налично
node tools/cdp-shot.mjs <url> out.png  # снимка като на телефон (Edge headless)
```
