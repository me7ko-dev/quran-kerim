> Предаване от облачната сесия на 25.09.2026. Устройството на приложението е в [SESSION_NOTES.md](SESSION_NOTES.md), а това е „докъде стигнахме и какво следва“.

## 1. Къде е кодът

Цялата работа от тази сесия е в клона **`claude/produlzhi-sus-suzdavaneto-lhp5h2`**, не в `main`.
Сайтът на живо (GitHub Pages) се публикува от `main`, затова **новото още не е на сайта**.

На лаптопа (Git Bash или PowerShell):

```bash
cd ~/Projects/quran-kerim
git status                      # да няма неизпратени промени; ако има — commit или stash
git fetch origin
git checkout claude/produlzhi-sus-suzdavaneto-lhp5h2
git pull
node tools/serve.mjs 8931       # после отвори http://localhost:8931
```

За да излезе на сайта, клонът се слива в `main`. Има два начина:
- в GitHub: *Pull requests → New → base: main ← compare: claude/produlzhi-sus-suzdavaneto-lhp5h2 → Merge*;
- или локално:

  ```bash
  git checkout main
  git pull
  git merge claude/produlzhi-sus-suzdavaneto-lhp5h2
  git push
  ```

Pages се обновява за около минута. Service worker-ът взима новата версия при следващото отваряне.

## 2. Какво е направено в тази сесия

- **Месечна проверка на времената за намаз** (`.github/workflows/update-prayer.yml`). Файлът липсваше, въпреки че README го описваше.
- **Кибла** (`#/qibla`, бутон на екрана „Намаз“):
  - компас на телефона (iPhone с разрешение, Android веднага);
  - поправка за магнитното отклонение;
  - часът, в който слънцето сочи киблата;
  - разстояние до Мека.
- **Заучаване на откъс:** всеки айет N пъти, после целият откъс M пъти или без край. Отваря се от „⋯“ на айет или от режима в плейъра.
- **Турски превод на Диянет** (Tanzil), по избор: Български / Türkçe / Двата. Търсенето разбира турските букви.
- **Шрифтовете са на сайта** (без Google Fonts): по-бързо, без проследяване, работят и без интернет.
- **Три независими прегледа на кода с поправки.** Бъговете, намерени при тях, имат тестове в `tools/test/regress.cjs`. Най-важните:
  - екранът за намаз премигваше между старото и новото място;
  - след скок в същата сура бутоните на айетите спираха да работят;
  - обратното броене грешеше с час в нощите на смяна на часовото време;
  - арабският шрифт не се зареждаше без интернет;
  - „Пусни“ не правеше нищо след неуспешно зареждане на аудиото;
  - „следи айета“ не минаваше в следващата сура;
  - „Продължете четенето“ пазеше айет по-назад, а при всяка смяна на изгледа позицията се връщаше с по един айет.
- **Достъпност:** 0 нарушения по axe на основните екрани в трите теми. Фокусът работи правилно в листовете.
- **Тесни екрани:** всички екрани се побират при 320 px.
- **Преки пътища на иконата** (Намаз, Кибла, Отметки) и заглавие на раздела по екрана.
- **Браузърни тестове в репото:** `node tools/test/run.cjs` (60 проверки, около 2 минути).

## 3. Какво НЕ можах да проверя (облакът блокира тези сайтове)

1. **Компасът на истински телефон.** Тестван е само със симулирани сензори. Трябва да се пробва:
   - iPhone: иска ли разрешение и върти ли се стрелката правилно;
   - Android: върти ли се веднага;
   - посоката: сравни с друго приложение за кибла (за София трябва да е около 142°).
2. **Първото пускане на workflow-а.** След сливането в `main`: GitHub → *Actions → „Времена за намаз“ → Run workflow*. Ако grandmufti.bg блокира сървърите на GitHub, проверката ще се проваля и тогава трябва друг подход.
3. **Аудиото от everyayah.com.** Пусни `node tools/check-reciters.mjs`, за да провериш, че и 25-те рецитатора са налични.

## 4. Идеи за после

- Известия за намаз. Изискват push сървър или отворено приложение, затова засега са отложени.
- Тефсир (кратко тълкувание под айета).
- Изтегляне на аудио за слушане без интернет. Внимание: Safari иска поддръжка на заявки за част от файла (range requests), затова трябва тест на iPhone.
